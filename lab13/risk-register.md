# Repair Tracker - Risk Register

| Risk | Probability | Impact | Mitigation Strategy |
|---|---|---|---|
| Database or customer data loss | Medium | High | Create regular database backups and test recovery. |
| Unauthorized access | Medium | High | Improve login security and test user permissions. |
| Docker deployment issues | High | High | Test the Docker container before the final release. |
| Not meeting the release date | Medium | High | Prioritize important tasks and track progress. |
| Code becoming difficult to maintain | Medium | High | Refactor duplicate code and keep files organized. |
| Invalid customer photo uploads | Medium | Medium | Validate file types and sizes before uploading. |
| Mobile layout issues | Medium | Medium | Test the website on different screen sizes. |
| Incorrect inventory information | Low | Medium | Validate inventory changes and test calculations. |
